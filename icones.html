Comment l'utiliser dans Umbraco

Sprite SVG (recommandé)

Inclure une fois muslim-hands-icons.svg dans le layout, puis appeler chaque symbole :

<svg class="ico" aria-hidden="true"><use href="#mh-drop"/></svg>

Fichiers séparés

Dossier icones/svg/ : un fichier par icône et par style (duotone, ligne, blanc), prêt pour la médiathèque Umbraco, Figma ou Canva.

Les icônes sont décoratives : aria-hidden="true", le texte voisin porte le sens.
